Royal House - Real Estate Management System

A Spring Boot application for managing real estate properties and administrative tasks. The system provides functionality for managing buildings, contacts, and site content.

Key Features: - Property management - Contact information management - About page content management - File upload capabilities - Administrative settings
Technology Stack: - Java 21 - Spring Boot - Spring Data JPA - PostgreSQL - Thymeleaf - Bootstrap 5.3.3 - Node.js with npm
