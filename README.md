Royal House - Real Estate Management System
Application for managing real estate properties and administrative tasks. The system provides functionality for managing buildings, contacts, and site content.

A full-stack web application developed using Spring Boot for managing real estate properties. 
Implemented comprehensive administrative features for property management, contact information, and content management. 
Designed and developed RESTful APIs for data handling and integrated front-end using Thymeleaf and Bootstrap.

Key Achievements:
 - Developed a secure admin panel with CRUD operations for property management
 - Implemented file upload system for property images and documents
 - Created dynamic content management system for website pages
 - Integrated contact management system with social media links

Technology Stack:
 - Backend: Java 21, Spring Boot, Spring Data JPA, PostgreSQL
 - Frontend: Thymeleaf, Bootstrap 5.3.3
 - Build Tools: Maven, Node.js with npm
 - Version Control: Git

Key Features: - Property management - Contact information management - About page content management - File upload capabilities - Administrative settings
